M1: The Depths of Dejenol(TM) Ordering Information

 

NOTE: Edited May 12,  2026

 

When you purchase M1 in download form you will get access to the legacy MyMordor page, providing access to the full updated installer which should allow you to play on most  Windows operating systems. The game is tested on WinXP sp3, Win7, Win10 and Win11 Pro but some Win11 Home Edition and other related versions seem to only play well with programs bought from the Microsoft store.

If you have a copy of the legacy software from 1994/1995 it will not run natively on 64bit systems. There are several ways to get round this, you could use virtual machines or load DosBox if you own a valid copy of 2bit Win3.1 or Win95.

 

We have a recent installer for the legacy software which sets the conditions which would allow an independent 3rd party application that redirects 64bit Windows to run 16bit software.  For further information visit https://decklinsdemise.com/mordor.htm
